# 📊 E-Commerce Sales Dashboard
## 📌 Project Overview

This project is an **E-Commerce Sales Analysis Dashboard** created using **Microsoft Excel**.

The main objective of this project is to transform raw e-commerce sales data into meaningful business insights using data cleaning, Pivot Tables, Pivot Charts, Slicers, and data visualization.

The dashboard provides an interactive view of sales, profit, customers, products, payment methods, order status, shipping modes, and state-wise sales performance.

## 🎯 Project Objectives

- Analyze overall sales and order performance
- Track total profit and average order value
- Analyze monthly sales trends
- Analyze sales by product category
- Identify top-performing products
- Identify top customers by sales
- Analyze state-wise sales performance
- Analyze different payment methods
- Analyze order status
- Compare different shipping modes
- Create an interactive Excel dashboard

## 📊 Key Performance Indicators (KPIs)

KPI

- Total Orders 
- Total Sales
- Total Profit 
- Total Customers
- Average Order Value
- Average Rating 


## 🧹 Data Preparation & Cleaning

The raw data was prepared and organized before creating the dashboard.

The process included:

- Checking the raw dataset
- Identifying data inconsistencies
- Standardizing data where required
- Organizing the data for analysis
- Creating Pivot Tables
- Creating Pivot Charts
- Applying Slicers
- Building the final interactive dashboard
